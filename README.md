# 📊 Customer Churn Prediction Dashboard

An interactive Streamlit-based web dashboard to:
- Perform exploratory data analysis (EDA)
- Train ML models (Logistic Regression, Random Forest, SVM)
- Predict customer churn using live inputs

## 🚀 How to Run

```bash
git clone https://github.com/YOUR_USERNAME/churn-dashboard.git
cd churn-dashboard
pip install -r requirements.txt
streamlit run app.py
